# NOUGHTS AND CROSSES GAME

A simple game written in python. Noughts and crosses or as known in American english
tick tack toe. It is played in the CLI where the first player is represented by Xs and the 
computer player represented by Os. The human player is always first to play. The game is not 
optimized for a strategic play which always ends a draw. Hence the possibility for the human 
player to win.
